# CSCI_4022_Final_Project
This project analizes the Wikispeedia dataset from Stanford (SNAP). The purpose of the analisis is to determine if Jaccard simularity or PageRank is best at determining human behviour and decisions for navigating through a network. After analizing the data using each of the methods we compair the results from each. After that we discuss next steps we can take to further investigate the best way to model human behaviour while navigating a network.
